# Негативные сценарии и ожидаемая реакция защищённой системы

| Номер | Сценарий | Ожидаемая реакция |
|---|---|---|
| НС-1 | Интерфейс связи с Землёй изменил корректную команду и передал ложные параметры открытия шлюза. | Подмена обнаружена проверкой подписи или валидатором команды. Команда отклоняется. |
| НС-2 | Интерфейс связи с кораблями передал поддельный запрос на стыковку. | Запрос отклоняется валидатором стыковки и проверкой источника. |
| НС-3 | Центральная система управления отправила команду открытия шлюза без проверки давления. | Политика безопасности блокирует команду. |
| НС-4 | Сервис управления шлюзами открыл внутреннюю и внешнюю створку одновременно. | Контроль шлюзов запрещает одновременное открытие створок. |
| НС-5 | Сервис управления доступом предоставил доступ в реакторный сектор пользователю без полномочий. | Валидатор прав доступа отклоняет операцию. |
| НС-6 | Сервис контроля отсеков передал ложные данные о нормальном давлении при разгерметизации. | Верификатор датчиков обнаруживает расхождение. |
| НС-7 | Сервис стыковки подтвердил соединение при неисправном стыковочном узле. | Валидатор стыковки запрещает подтверждение. |
| НС-8 | Центральная система управления подменила команду закрытия шлюза на открытие. | Проверка подписи и журнала команд обнаруживает подмену. |
| НС-9 | База данных состояний содержит ложный статус шлюза. | Мониторинг состояния обнаруживает несоответствие телеметрии. |
| НС-10 | Сервис журналирования не сохранил запись об аварийном открытии шлюза. | Монитор безопасности выявляет отсутствие обязательной записи. |
| НС-11 | Сервис мониторинга не сообщил об отказе питания шлюза. | Монитор оборудования фиксирует отказ питания. |
| НС-12 | Локальный терминал отправил несанкционированную команду разблокировки сектора. | Авторизация и политика безопасности отклоняют команду. |
| НС-13 | Аварийный модуль не перевёл систему в безопасный режим при разгерметизации. | Автоматический регулятор ЧС инициирует безопасный режим. |
| НС-14 | Интерфейс связи с Землёй повторно отправил устаревшую команду открытия шлюза. | Защита от повторной отправки отклоняет команду. |
| НС-15 | Интерфейс связи с кораблями исказил телеметрию и скрыл повреждение узла. | Валидатор стыковки и верификатор датчиков обнаруживают ложную телеметрию. |
| НС-16 | Центральная система отправила взаимоисключающие команды открытия и блокировки шлюза. | Анализатор событий обнаруживает конфликт команд. |
| НС-17 | Центральная система задержала аварийную команду закрытия шлюза до разгерметизации. | Монитор команд фиксирует задержку критической команды и запускает аварийный режим. |
